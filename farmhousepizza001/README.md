# Farmhouse Pizza and Donair — Website Redesign (`farmhousepizza001`)

Modern, responsive, bilingual (**English + French**) website redesign for **Farmhouse Pizza and Donair** (Landing Plaza, #110-5301 25th Ave, Vernon, BC V1T 9R1).

## Live Demo
- **GitHub Pages:** `https://tatran.github.io/redesign/farmhousepizza001/`

## Key Features
- **Bilingual (EN / FR):** Instant header switcher with `localStorage` persistence, `?lang=en|fr` URL support, dynamic `<html lang>`, and translated SEO `<title>` / `<meta name="description">`.
- **Dark & Light Themes:** Wood-Fired Dark Mode (default) and Warm Artisan Light Mode with zero-FOUC bootstrap and `localStorage` persistence.
- **Comprehensive SEO:**
  - Semantic HTML5, Open Graph, Twitter Cards, Geo tags for Vernon, BC, canonical + `hreflang` (`en-CA`, `fr-CA`, `x-default`).
  - Rich Schema.org JSON-LD `@graph` (`Restaurant`, `OpeningHoursSpecification`, `FAQPage`, `BreadcrumbList`).
  - `robots.txt` and `sitemap.xml`.
- **Interactive Menu Explorer:** 7 authentic categories (Pizzas, Donairs & Wraps, Calzones & Strombolis, Pasta & Rice Bowls, Wings & Dry Ribs, Appetizers & Sides, Family Deals & Kids), size/crust selectors, dietary filters (Favourites, Vegetarian, Gluten-Free Option, Halal, Spicy), live search, and a slide-over Order Estimation Tray.
- **In-House Delivery Calculator:** Interactive Vernon neighbourhood selector & distance slider calculating Farmhouse's real `$7 (first 6 km) + $1/km` delivery rate.
- **Live Open/Closed Status:** Computed in real time for `America/Vancouver` (Vernon, BC).
- **Promotional Outreach Email:** Ready-to-send HTML (`promotional-email.html`) and plain-text (`promotional-email.txt`) versions.
