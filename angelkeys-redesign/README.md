# Angelkeys Music Studio redesign

[English preview](https://livingpixelstudios.com/redesign/angelkeys-redesign/) · [Aperçu en français](https://livingpixelstudios.com/redesign/angelkeys-redesign/fr/) · [Bilingual promo email draft](promotional-email.md)

Serve this folder with a static HTTP server. English and Canadian French are separate, crawlable HTML pages. The theme follows the device until the visitor selects a preference, which the browser shares across both pages. The registration and portal links use the studio’s existing My Music Staff pages.

The canonical URLs, reciprocal language alternates, social image URLs and sitemap use the GitHub Pages preview address. For a cutover to the studio domain, update those URLs in both HTML files and in the sitemap. Keep the existing registration, portal and studio resource routes active or retarget the links to their new addresses, and add the sitemap to the production site’s root robots.txt.

Studio information and links come from the [current Angelkeys website](https://www.angelkeys.ca/). Angela’s portrait comes from the [Greater Vernon Chamber of Commerce member listing](https://business.vernonchamber.ca/list/member/angelkeys-music-studio-1897.htm). The hero is an ImageGen photograph of hands playing a black grand piano in warm window light. The bundled typefaces are licensed under the SIL Open Font License ([Instrument Serif](assets/Instrument-Serif-OFL.txt) and [DM Sans](assets/DM-Sans-OFL.txt)).
