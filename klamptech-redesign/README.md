# KLAMPTECH s.r.o. — Modern 4-Language Redesign (SK / DE / EN / PL)

Modern, responsive, SEO-optimized website redesign concept for **KLAMPTECH s.r.o.** (Nové Mesto nad Váhom, Slovakia — member of the **Cech strechárov Slovenska**).

## Live Preview
- **Slovensky (SK):** https://tatran.github.io/redesign/klamptech-redesign/?lang=sk
- **Deutsch (DE):** https://tatran.github.io/redesign/klamptech-redesign/?lang=de
- **English (EN):** https://tatran.github.io/redesign/klamptech-redesign/?lang=en
- **Polski (PL):** https://tatran.github.io/redesign/klamptech-redesign/?lang=pl

## Key Features
- **4 Full Languages (`SK | DE | EN | PL`):** Instant client-side language switching with `?lang=` URL synchronization, `localStorage` persistence, and dynamic `<title>` / `<meta name="description">` updates.
- **Dark & Light Mode:** Anthracite Slate Dark Mode and Blueprint Daylight Light Mode with 1-click header toggle and saved user preference.
- **Interactive Quote Builder:** Visitors select project type, material/system (standing seam, sheet metal, tile framing, Fatrafol/Sklobit/Hydrobit, custom workshop profiles), and approximate area to pre-fill their inquiry.
- **Real Project Gallery & Lightbox:** 12 real completed project photos from `klamptech.sk` with lazy loading and keyboard-accessible lightbox.
- **Complete SEO & Legal Compliance:** Schema.org `RoofingContractor` JSON-LD, `hreflang` alternates, `sitemap.xml`, `robots.txt`, full Slovak company registration details (IČO, DIČ, IČ DPH, IBAN, OR OS Trenčín), embedded Nové Mesto nad Váhom map, and localized GDPR modal.
- **Promotional Outreach Email:** Ready-to-send HTML (`promotional-email.html`) and plain-text (`promotional-email.txt`) versions.
