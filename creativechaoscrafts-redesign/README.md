# Creative Chaos Crafts redesign

Responsive English and Canadian French redesign concept for the Creative Chaos Festival in Vernon, BC. Independent concept; the original domain remains under its owner's control.

## Run

No dependencies or build step required to serve the site. Run `node serve.mjs` and open http://127.0.0.1:8097/. To regenerate the two HTML pages and sitemap after copy changes, run `node build.mjs` from this folder.

## Included

- Separate indexable EN and FR pages, with complete translated visitor information.
- Light/dark themes, system preference on first visit, persistent manual selection.
- Responsive navigation, keyboard focus styles, skip link, reduced-motion support and native FAQ disclosure controls.
- Three-event calendar download, live directions, email/phone links and official exhibitor/application links.
- Canonical and reciprocal hreflang URLs, Open Graph/Twitter metadata, Festival JSON-LD, sitemap and robots file.
- Draft promotional email in English and French, as HTML and plain text. No email has been sent.
