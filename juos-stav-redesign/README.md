# JuOs-Stav redesign

Responsive static redesign for [JuOs-Stav](https://juos-stav.sk/), adapted from the repository's [DOPTECH template](../doptech-redesign/). The site uses JuOs-Stav's published logo, service photography and contact details. Inter is bundled under the [SIL Open Font License](fonts/OFL.txt).

Open `index.html` or serve this directory with any static web server. No build or dependencies are required. Slovak is the default language. Visitors can switch to German, English or Hungarian, and links can open directly in a language via `?lang=sk`, `?lang=de`, `?lang=en` or `?lang=hu`. The site follows the device theme until a visitor selects light or dark mode. The browser stores both preferences locally.

The inquiry form opens a prefilled message in the visitor's email app. The site has no submission backend. The contact section includes a lazy-loaded Google Maps iframe for the company's address.
