# Venice.sk redesign

A Slovak homepage redesign for Venice.sk covering company formation, registered offices, and ready-made companies. Service and pricing links lead to the original site.

The site is static. To preview it, run a local web server from this directory and open the address it prints. For example, with Python installed:

```sh
python -m http.server 8080 --bind 127.0.0.1
```

Open [http://127.0.0.1:8080](http://127.0.0.1:8080). For static hosting, use this directory as the site root.

The hero image was generated with ImageGen. The bundled Manrope fonts are distributed under the [SIL Open Font License](assets/Manrope-OFL.txt).
