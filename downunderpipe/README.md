# Down Under Pipe Inspection Ltd. — Bilingual Redesign (EN / FR)

Modern, high-conversion static website redesign for **Down Under Pipe Inspection Ltd.** (Vernon, BC — family-owned since 1998, led by Mark Tishenko).

## Features
- **Full English + French (`EN` / `FR`) Bilingual Parity:** 1-click language switcher updating all UI text, interactive diagnostic results, SEO `<title>`, meta description, and `<html lang>` with `localStorage` and `?lang=en|fr` URL support.
- **Dark & Light Themes:** Subsurface Slate Dark Mode and Blueprint Daylight Light Mode with FOUC-free bootstrap and persistent user preference.
- **Interactive Pipe Diagnostic & Equipment Matcher:** Helps residential, commercial, and municipal callers match their pipe diameter and symptoms to the right camera system (**Vivax Push Camera 50–150 mm** vs. **Rovver Robotic Crawler 150–900 mm**) and service path (CCTV, Cleaning, CIPP Trenchless Relining, or Locating).
- **CIPP Trenchless vs. Traditional Excavation Comparison:** Clear side-by-side breakdown showing how no-dig relining protects driveways, gardens, and landscaping.
- **Local Vernon & Okanagan SEO:** Full Schema.org JSON-LD (`Plumber` / `LocalBusiness`, `Service` catalog, `FAQPage`, `BreadcrumbList`), geo meta tags (`CA-BC`, Vernon), canonical + `hreflang` (`en-CA`, `fr-CA`, `x-default`), Open Graph & Twitter Cards, `robots.txt`, and `sitemap.xml`.
- **Promotional Outreach Email:** Ready-to-send `promotional-email.html` and `promotional-email.txt`.
